# 課程內容撰寫規格

本專案是給台灣使用者的「國外日常生活英文」學習網站。目標：讓學習者能在國外流暢生活——點餐、叫車、購物、small talk、聽懂俚語、能自然接話——而不是商業英文。

## 檔案格式

每個單元一個檔案：`src/data/units/<unit-id>.ts`，格式：

```ts
import type { Unit } from '../types';

const unit: Unit = {
  id: '<unit-id>',
  // ...完整內容
  videos: [], // 一律留空，影片由 videos.ts 另行合併
};

export default unit;
```

型別定義見 `src/data/types.ts`，每個欄位都有註解說明。**必須完全符合型別**，不得有 TS 錯誤。字串含單引號時注意跳脫。

## 內容量要求（每單元）

- `dialogues`：至少 2 段，每段 10–16 句。第一段是標準情境，第二段要有變化（出問題、被反問、需要臨場反應的狀況）。
- `vocab`：至少 24 個，選「真的會遇到但課本不教」的字。
- `phrases`：至少 10 個，一定要包含「怎麼開口」「怎麼接話」「怎麼委婉拒絕/追問」的句型模板。
- `quiz`：8 題，考情境反應（「服務生問你 X，你該怎麼回？」），不考文法。
- `culture`：2–3 則文化眉角（小費、排隊、禁忌話題等）。

## 語言風格

- 英文：自然美式口語為主，包含縮讀（gonna、wanna、lemme）、填充詞（like、you know）、真實服務業用語（"For here or to go?"、"Are you all set?"）。偶爾備註英式差異。
- 中文：繁體中文、台灣用語。解說要講「為什麼這樣說」「直翻為什麼行不通」「講錯會多尷尬」，像懂美國生活的朋友在旁邊教你，不要像教科書。
- `note` 欄位是本站的靈魂：解釋語氣、潛台詞、替代講法。例如 "How are you?" 不是真的在問你好不好；"I'm good" 在點餐時是「不用了」的意思。

## 品質原則

- 寧可深不要廣：一個講透的情境勝過十個蜻蜓點水。
- 對話要能真的照著用：學習者到美國把台詞唸出來要能成功點到餐、叫到車。
- 俚語標明使用場合與年齡層，過時俚語（如 groovy）不收，除非特別註明「聽得懂就好，別用」。
