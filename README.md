# Small Talk Society · 道地美式閒聊

每天 30 分鐘，練出道地美式 small talk。旅行時點餐、問路、跟陌生人聊天，加上商務會議前、中、後的閒聊。整體氛圍參考《瘋狂亞洲富豪》（Crazy Rich Asians）：紐約、新加坡、豪門家宴、世紀婚禮。

## 核心學習法：Toko 模式

1. **先學會整段**：聽懂對話、看中英對照、記重點片語
2. **跟讀模仿**：逐句模仿美國腔的連音與語調，錄音後自動比對
3. **看中文說英文**：只看中文提示，直接開口說出整句英文，再對答案、自評
4. **間隔複習**：答得越輕鬆，下次出現的間隔越長（SM-2 演算法）

## 功能

| 功能 | 說明 |
|---|---|
| 今日課表 | 平日 5 步驟約 30 分鐘：暖身複習 → 聽懂對話 → 跟讀 → Toko 中翻英 → 作業 |
| 週末總複習 | 週六：本週卡片總複習＋Toko 全週挑戰＋寫對話；週日：角色扮演＋到期複習＋週回顧 |
| 20 堂情境課 | 4 週課程：旅行 I（點餐、問路）、旅行 II（派對、見家長）、商務 I（會議前）、商務 II（會議中與會後） |
| 美式發音 | 每課 2–3 個美國腔重點（flap T、連音、弱化），全部可播放 |
| 跟讀＋語音辨識 | 錄音辨識你說的話，標出漏掉的字，並可回放自己的聲音和原音對照 |
| 角色扮演 | 對方台詞由語音演出，輪到你時只看中文提示，可開「盲聽模式」 |
| 單字本 | 完成課程自動加入片語；任何句子都能按 ⭐ 收藏；可自訂新增、搜尋、篩選 |
| 進度追蹤 | 每日學習分鐘（自動計時）、連續天數、熱度圖、每週長條圖、Toko 答對率、課程地圖 |
| 作業 | 每課專屬作業，可打字或口述輸入，自動儲存並保留紀錄 |

課程進度會「接續」：漏掉一天不會跳課，隔天會從下一堂未完成的課開始。20 堂課全部完成後，自動進入複習循環。

## 建議使用環境

- **最佳美國腔**：Microsoft Edge（內建 Aria、Jenny、Guy 等 Natural 神經語音）
- **Mac／iPhone**：設定 → 輔助使用 → 朗讀內容 → 聲音 → 英文（美國），下載 Ava、Evan（進階），再到網站「設定」頁選擇
- **語音辨識**：Chrome、Edge、Safari 支援；Firefox 不支援，可改用打字作答
- 第一次使用麥克風時，瀏覽器會詢問權限，請按「允許」

> 學習紀錄存在瀏覽器的 localStorage。換裝置前請到「設定 → 匯出備份」，在新裝置「匯入備份」。

## 本機執行

純前端靜態網站，不需要安裝任何套件。

```bash
npm start          # 在 http://localhost:8080 啟動
npm test           # 執行單元測試（Node 18+）
```

也可以用任何靜態伺服器（例如 `python3 -m http.server`）。直接雙擊 `index.html` 無法使用，因為瀏覽器會擋下 ES modules。

## 部署到 GitHub Pages（免費、手機也能用）

1. 把程式合併到 `main` 分支
2. GitHub repo → **Settings → Pages**
3. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
4. 約 1 分鐘後，網址會是 `https://<你的帳號>.github.io/English-Learning-/`
5. 手機用 Safari／Chrome 打開 →「加入主畫面」，就能像 App 一樣使用（支援離線）

## 專案結構

```
index.html              版面與導覽列
css/style.css           樣式（翡翠綠 × 香檳金，支援深色模式）
js/app.js               路由、學習時間追蹤
js/data/week1-4.js      課程內容（對話、片語、發音、在地小知識、作業）
js/plan.js              每日課表、課程完成判定、連續天數
js/srs.js               間隔重複演算法
js/text.js              英文答案比對（縮寫展開、逐字標示）
js/speech.js            美式語音合成、語音辨識、錄音
js/components/          對話、跟讀、Toko 練習、角色扮演元件
js/views/               各頁面
tests/                  單元測試
```

## 新增課程

在 `js/data/` 新增 `week5.js`（格式與 `week1.js` 相同），再到 `js/data/lessons.js` 匯入並加到 `WEEKS` 與 `LESSONS`。台詞中的 `{name}` 會自動換成你在設定頁填的英文名字。
